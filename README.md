# link-redirect

A GitHub Pages redirect page that exposes Open Graph metadata for one YouTube
Short, then opens another Short for a browser visitor.

## Publish on GitHub Pages

1. Push this repository's `main` branch to GitHub.
2. In the GitHub repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/ (root)`, then save.
5. GitHub will publish the page at `https://prkr88.github.io/link-redirect/`.

For a fresh WhatsApp preview while testing, append a new query string each time,
such as `?v=2`. WhatsApp can cache a previously fetched card.

The visible link remains the GitHub Pages (or custom) domain. Do not use a
lookalike domain intended to impersonate YouTube.
